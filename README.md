# Speezy

### Reimagining cross-border payments with intelligent routes built for how money should move.

Speezy is exploring a simpler way to pay across borders.

The goal is simple:

**Cross-border payments should feel as easy as paying with UPI.**

Users shouldn't have to understand payment rails, currency conversion, intermediaries, cards, wallets, or routing logic.

They should simply pay.

Speezy handles the complexity underneath.

---

## The idea

Today, paying a foreign merchant can require navigating unfamiliar payment methods, cards, wallets, currency conversions, and payment restrictions.

Speezy approaches the problem differently.

Instead of asking:

> "Which payment method does this merchant accept?"

Speezy asks:

> **"How can we get this merchant paid?"**

The system then explores viable payment routes and selects the best available path.

Foreign Checkout
       ↓
Payment Intent
